웹 푸시 — 마지막 배포 단계

앱을 닫아도 오는 @멘션 알림을 켜려면 발송 함수 하나를 배포해야 해요. 클라이언트 코드와 함수 코드는 다 만들어뒀고, 아래 붙여넣기 3번이면 끝납니다.

이미 제가 해둔 것: Railway에 VITE_VAPID_PUBLIC_KEY 등록 · push_subscriptions 테이블 · SW 푸시 수신 코드 · "동행자 알림" 토글에 구독 등록 연결.

A · SQL 한 줄 추가 (30초)

push_subscriptions에 이름 컬럼을 추가합니다. Supabase → SQL Editor에 붙여넣고 RUN:

alter table public.push_subscriptions add column if not exists display_name text;

B · Edge Function 배포 (5분)

  1. Supabase → Edge Functions → Deploy a new function (또는 "Via Editor")
  2. 함수 이름: push-notify
  3. 기본 코드를 다 지우고, 리포의 supabase/functions/push-notify/index.ts 내용을 전체 복사 → 붙여넣기
    GitHub: on-mom/MamMoose/…/push-notify/index.ts
  4. Deploy 클릭

C · 시크릿 3개 등록 (2분)

Edge Functions → Secrets (Manage secrets) 에서 Add new secret 3번:

이름값

VAPID_PRIVATE_KEY마음님이 web-push generate-vapid-keys 로 만든 Private Key (채팅에 보내주셨던 rW7b… 값)

개인키(Private Key)는 이 시크릿 저장소에만 넣고, 다른 데(코드·채팅·메모 공유)엔 남기지 마세요. 여기 넣으면 아무도 다시 못 봅니다(정상).

D · 확인 (1분)

  1. 배포된 앱에서 MY → 설정 → "동행자 알림" 켜기 → 브라우저가 물으면 허용
  2. Supabase → Table Editor → push_subscriptions 에 방금 내 기기 행이 생겼는지 확인
  3. 두 분이 각자 폰에서 1·2를 하고, 한 명이 코멘트에 @상대이름을 넣어 등록 → 상대 폰에 알림이 오면 성공 🎉
iOS(아이폰)는 사파리에서 "홈 화면에 추가"로 앱을 설치한 상태에서만 푸시가 옵니다. 안드로이드/데스크톱은 그냥 됩니다.
배포 안 해도 되는 것 — @멘션 시 앱을 켜 둔 상태의 알림은 이미 동작합니다(실시간 동기화 + 로컬 알림). 위 배포는 "앱을 완전히 닫았을 때도" 오게 하는 단계예요. 급하지 않으면 나중에 하셔도 됩니다.
