현상

관광지(추천 스팟)·맛집·숙소가 서로 다른 탭/화면에 흩어져 있고, 필터 방식도 제각각.

목표 화면 동작

  1. 1차 — 지역 : 구글시트처럼 여러 구역을 동시에 선택. 가로 스크롤 칩.
  2. 2차 — 종류 : [랜드마크/관광지] [맛집·카페·식당] [숙소] 3버튼. 1차로 걸러진 결과 기준.
  3. 1↔2차 순서 토글 : “지역 먼저 → 종류” ⇄ “종류 먼저 → 지역”. 상단 ⇅ 한 번으로 전환.
  4. 3차 — 세부 + 정렬 : 종류별 세부 카테고리(사원·공원·박물관 / 현지식·커피·뷔페 …) + 가격·평점·이름 정렬.
  5. 담기 : 각 카드의 ＋로 타임라인에 바로 추가 (기존 ‘추천 스팟 담기’ 동작 유지).

데이터 — 통합 Place 타입 (기획서 그대로)

Place { kind: 'landmark' | 'food' | 'stay', name, nameKo, area, category, coords, priceText, note, menu, mapUrl }
기존 spots / restaurants / hotels → places 하나로 마이그레이션(persist v5). 맛집 탭·숙소 뷰도 이 위에서 재구성.
