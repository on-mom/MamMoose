배포 전 vs 배포 후

배포해도 되는 상태 — 핵심 요구사항은 다 들어갔고, 큰 버그(드래그)도 잡혔습니다. 아래는 있으면 더 좋은 것들.
배포 후 천천히
  • 구역 가이드 — xlsx "지역별 특성"의 구역별 관광·맛집·카페·쇼핑·현지 정서·놀이시설. 여행 준비에 유용한 마지막 미사용 데이터 (1~2시간)
  • 가계부 예산 초과 도장 · MY D-Day 커플 일러스트 (마스코트 이미지 1장 더 필요)
  • 항공권 정보 구조화 입력 · 채팅 실시간성 개선
  • 구글 지도 API 키 연동 → 동선·미니맵 실제 지도 + 택시 소요시간 실시간화 (아래 참고)

구글 지도 세팅 — 남은 단계

키는 이미 앱에 넣었고 동선 탭에 진짜 구글 지도가 뜨는 것까지 확인했습니다 (Maps JavaScript API 활성화됨). 아래 2가지만 더 하면 "위치 자동"과 "택시 소요시간 실시간"이 켜집니다.

✓ 끝난 것 — API 키 발급 · 앱 연동 · Maps JavaScript API 활성화 · 동선/미니맵이 실제 구글 지도로 표시
  1. API 2개 더 활성화 — API 라이브러리에서 검색 → 각각 사용:
    • Geocoding API — 장소명 → 지도 위치 자동 찾기
    • Distance Matrix API — 숙소별 공항/도심 택시 소요시간 실시간
    (안 켜도 앱은 정상 — 자동으로 구역 중심점 / 정적 추정치로 폴백)
  2. API 키 보호 (첨부하신 화면) — "제한 유형 선택"에서 웹사이트 선택 → 아래 항목들 추가:
    localhost:5173/*
    localhost:*/*
    *.up.railway.app/*
    배포 주소가 정해지면 마지막 줄을 실제 주소로 바꿔도 됨
  3. 같은 화면에서 API 제한사항 → "키 제한" → 아래 3개만 체크 → 저장: Maps JavaScript API Geocoding API Distance Matrix API
  4. 결제 계정 — 아직 없으면 안내대로 카드 등록 ($300 크레딧, 이 앱 사용량으론 요금 거의 0). 부담되면 지도만 쓰고 나머지는 폴백으로 둬도 됨.
  5. 배포할 때 Railway Variables에도 키 추가:
    VITE_GOOGLE_MAPS_API_KEY = (같은 키)
⚠️ 키가 이 문서와 채팅에 노출됐으니, 위 웹사이트 제한을 꼭 걸어주세요. 그러면 다른 사이트에서 이 키로 요청해도 거부됩니다. (Maps JS 키는 원래 브라우저에 노출되는 게 정상이라 제한만 걸면 안전)
