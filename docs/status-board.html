3 · 대화 후반에 나온 요청·수정

요청상태결과
서버가 있으면 안정적인가?답변상시 서버 불필요. 필요한 3가지(푸시·예약·비밀키)는 서버리스(Edge Function)로
가계부 통화 선택 (₫/₩)완료금액 입력 시 드롭다운. 원 입력하면 자동 환산 저장
프로필 사진 등록 오류완료원인 = 큰 사진 저장 한도 초과. 자동 압축 + 배경은 동기화 제외로 수정
지역 필터 = DATE POP식 + 넓은 범주완료세분 20여 개 → 큰 존 6개, 이모지 카드로
장소 뷰 → 맛집 탭으로 이동 + 팝업 검색완료맛집 탭 = [장소][숙소]. 일정 탭은 [타임라인][동선]
지역별 소개 / 랜드마크 데이터 살아있나?완료구글맵 링크 14곳·관광지 15곳은 장소 뷰에 반영됨. xlsx “지역별 특성” 시트도 구역 가이드(MY›도구)로 방금 살림
모든 코멘트에 @참여자 멘션 + 멘션 푸시3차멘션 UI는 가능하나, 푸시 알림은 웹 푸시 인프라와 함께
