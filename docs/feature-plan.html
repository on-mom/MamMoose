맘무스 추가 기능 10선 · 진행 계획 & 준비물

10가지 다 만들어요. 대부분은 준비물이 없어요.

좋게 봐주셔서 감사해요. 10개 중 7개는 계정·키가 전혀 필요 없어 바로 만들면 되고, 나머지 3개만 5~10분짜리 설정이 필요합니다. 아래에 딱 그 부분만 클릭 순서로 정리했어요.

준비물 없음 제가 바로 만듦 · 당신 설정 필요 아래 체크리스트 · 쉬움 난이도

A · 10가지 한눈에

기능한 줄준비물난이도
1. PWA 오프라인홈 화면에 앱처럼 설치 · 현지 인터넷 끊겨도 일정·맛집·지도 열림없음중
2. 구글맵 길찾기타임라인 각 장소에 “길찾기” → 구글맵 앱 내비 바로 실행없음쉬움
3. 여행 요약 카드여행 끝나면 자동 생성 (“3일 · 12곳 · 47만원 · 분짜 3번”) → 이미지 저장없음중
4. 사진 첨부타임라인·일기에 사진 1~2장 (자동 압축, 여행 문서에 저장)없음 ¹중
5. D-day 위젯MY 홈에 큰 카운트다운 + 커플 맘무없음쉬움
6. 우리 여행 규칙“기상 8시 · 하루 예산 10만원” 고정 메모 핀없음쉬움
7. 하노이 날씨일정 탭 상단에 일차별 날씨 (무료 API, 키 불필요)없음쉬움
8. 베트남어 카드택시·식당·숫자 미니 회화 20개없음쉬움
9. 환율 계산기가계부 안 거치고 “이거 얼마?” 빠른 계산 + 자주 쓰는 금액없음쉬움
10. 이동시간 경고“12시 다음 일정인데 이동만 40분” 자동 체크구글 API 1개중
+ 웹 푸시앱을 닫아도 오는 코멘트·추억함 알림푸시 키중상

¹ 사진을 아주 많이(수십 장) 넣고 싶으면 Supabase Storage 버킷을 쓰는 게 좋아요 — 그 경우만 아래 C 참고. 기본은 설정 없이 갑니다.

B · 진행 순서 (제안)

  1. 1차 — 트립 대비 : ① PWA 오프라인 · ⑦ 날씨 · ⑧ 베트남어 카드 · ② 길찾기. (하노이에서 바로 쓸모)
  2. 2차 — 감성·기록 : ④ 사진 첨부 · ③ 여행 요약 카드 · ⑤ D-day 위젯 · ⑥ 여행 규칙
  3. 3차 — 다듬기 : ⑨ 환율 계산기 · ⑩ 이동시간 경고 · 웹 푸시

1차는 준비물이 하나도 없어서 승인만 주시면 바로 시작합니다. 2·3차 진행 중에 아래 C·D·E를 병행해 주시면 돼요.

C · 당신이 할 일 — 딱 3가지

C-1 · 구글 클라우드 콘솔에서 API 2개 켜기 기능 10

약 3분 · 무료 (월 $200 크레딧 안에서 사용) · 이미 만들어 둔 지도 키 그대로 사용
  1. console.cloud.google.com/apis/library 접속 (지도 키 만든 그 계정)
  2. 상단에서 프로젝트가 지도 키를 만든 프로젝트인지 확인
  3. 검색창에 Distance Matrix API → 클릭 → [사용] (Enable)
  4. 다시 검색창에 Geocoding API → 클릭 → [사용] (지도 장소 위치 정확도도 같이 좋아져요)
  5. 사용자 인증 정보(Credentials) → 지도 키 클릭 → 애플리케이션 제한을 “HTTP 리퍼러”로, 아래 3개 추가:
    localhost:5173/*   localhost:*/*   *.up.railway.app/*
  6. API 제한에서 “키 제한” → Maps JavaScript API, Geocoding API, Distance Matrix API 3개만 체크 → 저장
지도 키(AIza…)는 이미 코드·배포에 들어가 있어요. 위 6번의 리퍼러 제한을 걸어두면 남이 훔쳐 써도 다른 사이트에선 작동 안 하니 꼭 해주세요.

C-2 · 웹 푸시 — 온마음 푸시 정보 공유 푸시 알림

온마음 사이트에서 이미 쓰신다니, 그 설정을 재활용하는 게 제일 빠릅니다

아래 3가지를 알려주시면 맘무스에 붙일 수 있어요. (온마음 개발하신 분께 물어보시면 바로 나옵니다)

  1. VAPID 공개키 (Public Key) — B… 로 시작하는 88자 내외 문자열. 비공개키는 절대 공유 금지
  2. 구독 등록 방식 — 브라우저가 만든 구독 정보(endpoint)를 어디로 POST 하면 되는지 (URL 1개) · 또는 “Supabase에 저장해 주세요”
  3. 발송 트리거 — 온마음처럼 서버가 자동으로 쏘는 구조인지, 아니면 제가 Supabase Edge Function으로 만들어야 하는지
잘 모르시겠으면 “Supabase로 알아서 해주세요”라고만 해주셔도 됩니다. 그 경우 Supabase 액세스 토큰 발급 한 번(제가 안내)만 해주시면 제가 구독 저장 + 발송 함수까지 다 만듭니다.

C-3 · 선택 Supabase Storage 버킷 — 사진을 아주 많이 넣을 때만

약 4분 · 기본(문서에 압축 저장)으로도 수십 장은 괜찮아서, 나중에 필요하면 하셔도 됩니다
  1. Supabase → Storage → New bucket
  2. 이름 trip-photos · Public bucket 체크 · Create
  3. 버킷 클릭 → Policies → “For full customization…” → 아래 정책 추가:
    SELECT(읽기): true · INSERT(업로드): auth.role() = 'authenticated'
  4. 완료되면 “버킷 만들었어요” 한마디만 주세요 — 제가 사진 첨부를 Storage 방식으로 전환합니다

D · 배포 후 · 두 분 각자 폰에서 (30초)

  1. 홈 화면에 추가 — 사파리/크롬에서 맘무스 열고 → 공유 버튼 → “홈 화면에 추가”. 이러면 주소창 없는 앱처럼 뜨고 오프라인에서도 열려요 (기능 1)
  2. 알림 허용 — MY → 설정 → “동행자 알림” 켜기 → 브라우저가 물어보면 허용 (기능: 코멘트·추억함·푸시 알림)
  3. 위치 권한 — 길찾기·현재위치 쓸 때 한 번 물어봄 → 허용 (기능 2·10)

E · 구글 드라이브 2TB는?

알려주셔서 감사해요. 다만 웹앱에서 개인 구글 드라이브에 파일을 넣으려면 매번 구글 로그인 창을 거쳐야 하고 설정이 복잡해서 — 사진은 Supabase(이미 연결됨)가 훨씬 매끄럽습니다. 드라이브는 원본 사진 백업 용도로 두 분이 직접 쓰시는 걸 추천드려요. 앱에서 “이 사진 드라이브에 열기” 링크 정도는 넣어드릴 수 있어요.

정리 — 승인 주시면 1차(1·7·8·2)부터 바로 시작합니다. 그동안 C-1(구글 API)만 먼저 해두시면 좋고, C-2·C-3는 2·3차 때 천천히요.
