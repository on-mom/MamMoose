카카오·구글 로그인과 동행자 공유를 켜기 위한 4단계 준비

맘무스 앱에 회원가입(카카오/구글)과 동행자 초대·실시간 공유를 붙이려면 데이터와 로그인을 맡아줄 서버가 필요합니다. Supabase라는 무료 서비스를 씁니다. 코딩은 필요 없고, 웹사이트 4곳에서 버튼을 누르고 값을 복사하는 작업입니다.

아래 순서대로만 하면 됩니다. 전부 지금 바로 가능하고, 앱을 인터넷에 올리는(Railway 배포) 작업은 나중에 해도 됩니다. 총 약 30분.

1Supabase 프로젝트 만들기  — 여기서 나오는 콜백 주소를 2·3단계에서 씁니다 2구글 로그인 연결 3카카오 로그인 연결 4Supabase에 앱 주소 등록
💡 준비물 — 구글 계정, 카카오 계정, 그리고 GitHub 계정(없으면 Supabase 가입 때 이메일로 가입 가능). 진행 중 헷갈리면 그 화면을 스크린샷 찍어서 채팅에 붙여넣어 주세요. 바로 짚어드리겠습니다.

STEP 1 · Supabase

Supabase 프로젝트 만들기

약 5분
  1. supabase.com 접속 → Start your project → GitHub 계정으로 로그인(또는 Continue with Email로 이메일 가입).
  2. New project 클릭. 조직(Organization)이 없으면 이름을 하나 입력해 새로 만듭니다 (예: onmom).
  3. 프로젝트 정보 입력
    • Name: mammoose
    • Database Password: Generate a password 클릭 → 나온 비밀번호를 메모장 등에 저장 (지금은 안 쓰지만 나중에 필요). 채팅엔 붙여넣지 마세요.
    • Region: Northeast Asia (Seoul) 선택 — 한국에서 가장 빠릅니다.
    • Plan: Free
  4. Create new project → 1~2분 기다리면 준비 완료.
  5. 왼쪽 맨 아래 Project Settings(톱니바퀴 아이콘) → API 메뉴로 이동.
  6. Project URL 복사 → 이것이 앱에 넣을 첫 번째 값입니다.
    https://프로젝트ID.supabase.co
  7. 같은 화면의 Project API keys에서 anon / public 키(아주 긴 문자열)를 복사 → 앱에 넣을 두 번째 값. (새 UI에서는 publishable 키로 표시될 수도 있습니다. 둘 중 있는 것.)
    이 두 값은 공개되어도 안전한 값이라 나중에 채팅으로 주셔도 됩니다. 반대로 service_role / secret 키는 절대 공유하지 마세요.
  8. 마지막으로 콜백 주소를 메모해 둡니다. Project URL 뒤에 /auth/v1/callback을 붙인 형태:
    https://프로젝트ID.supabase.co/auth/v1/callback
    👉 2단계(구글)와 3단계(카카오)에서 이 주소를 붙여넣습니다. 프로젝트ID 부분은 본인 값으로 바꾸세요.

STEP 2 · Google

구글 로그인 연결

약 10분

A. 구글 클라우드에서 로그인 키 만들기

  1. console.cloud.google.com 접속 → 구글 로그인.
  2. 상단 프로젝트 선택 메뉴 → 새 프로젝트 → 이름 mammoose → 만들기 → 만든 프로젝트를 선택.
  3. 왼쪽 메뉴(또는 상단 검색창)에서 API 및 서비스 → OAuth 동의 화면 (신 화면에서는 Google 인증 플랫폼).
    • User Type: External(외부) → 만들기
    • 앱 이름 맘무스, 사용자 지원 이메일·개발자 이메일에 본인 이메일 입력 → 저장 후 계속
    • 범위(Scopes) 화면은 그대로 저장 후 계속
    • 테스트 사용자: + ADD USERS → 본인 구글 이메일 + 동행자 구글 이메일 추가 → 저장 후 계속
    앱이 “테스트” 상태인 동안엔 여기 등록한 이메일만 로그인됩니다. 나중에 게시(Publish)하면 누구나 로그인할 수 있습니다 (기본 정보만 쓰므로 별도 심사 없음, 경고 화면만 표시).
  4. API 및 서비스 → 사용자 인증 정보 → 상단 + 사용자 인증 정보 만들기 → OAuth 클라이언트 ID
    • 애플리케이션 유형: 웹 애플리케이션
    • 이름: mammoose web
    • 승인된 리디렉션 URI → + URI 추가 → 1단계의 콜백 주소 붙여넣기:
    https://프로젝트ID.supabase.co/auth/v1/callback
    → 만들기
  5. 팝업에 나온 클라이언트 ID와 클라이언트 보안 비밀번호(Client Secret)를 복사.
    이 둘은 Supabase에만 입력합니다. 채팅에 붙여넣지 마세요.

B. Supabase에 붙여넣기

  1. Supabase 대시보드 → 왼쪽 Authentication → Sign In / Providers → 목록에서 Google 클릭.
  2. Enable Sign in with Google 켜기 → Client ID에 클라이언트 ID, Client Secret에 보안 비밀번호 붙여넣기 → Save.

STEP 3 · Kakao

카카오 로그인 연결

약 10분

A. 카카오 개발자 앱 만들기

  1. developers.kakao.com → 카카오계정 로그인 → 상단 내 애플리케이션 → 애플리케이션 추가하기
    • 앱 이름: 맘무스
    • 사업자명: 개인이면 본인 이름 또는 팀 이름
  2. 만든 앱 클릭 → 왼쪽 앱 설정 → 앱 키 → REST API 키 복사 (Supabase에서 “Client ID”로 씁니다).
  3. 왼쪽 카카오 로그인 → 활성화 설정을 ON.
  4. 같은 페이지 아래 Redirect URI → Redirect URI 등록 → 1단계 콜백 주소 붙여넣기 → 저장:
    https://프로젝트ID.supabase.co/auth/v1/callback
  5. 왼쪽 카카오 로그인 → 동의항목에서 닉네임을 “필수 동의”로 설정 (프로필 사진·이메일은 선택).
    이메일 항목은 별도 검수가 필요할 수 있습니다. 닉네임만으로도 로그인은 작동하니 우선 닉네임만 켜고 넘어가도 됩니다.
  6. 왼쪽 앱 설정 → 플랫폼 → Web 플랫폼 등록 → 사이트 도메인에 추가:
    http://localhost:5173
    (인터넷 배포 후에는 그 주소도 여기에 추가합니다.)
  7. 왼쪽 앱 설정 → 보안 → Client Secret → 코드 생성 → 상태를 사용함(ON)으로 → 생성된 코드 복사 (Supabase에서 “Client Secret”으로 씁니다).

B. Supabase에 붙여넣기

  1. Supabase → Authentication → Sign In / Providers → Kakao 클릭 → 켜기.
  2. Client ID에 REST API 키, Client Secret에 방금 생성한 Client Secret 코드 붙여넣기 → Save.

STEP 4 · Supabase

Supabase에 앱 주소 등록

약 3분
  1. Supabase → Authentication → URL Configuration.
  2. Site URL: 개발 중에는 아래 값으로 둡니다 (배포 후 Railway 주소로 변경).
    http://localhost:5173
  3. Redirect URLs → Add URL로 아래를 추가:
    http://localhost:5173/**
    https://앱이름.up.railway.app/**
    (Railway 배포 주소가 아직 없으면 첫 줄만. 배포 후에 두 번째 줄 추가.)
  4. Save.

다 됐으면 — 저에게 이 2개만 보내주세요

채팅창에 아래 두 값을 붙여넣어 주시면 로그인·공유 기능 코드를 이어서 만들겠습니다. 둘 다 공개돼도 안전한 값입니다.

VITE_SUPABASE_URL = https://프로젝트ID.supabase.co
VITE_SUPABASE_ANON_KEY = anon/public 키
🔒 이건 절대 채팅에 붙여넣지 마세요 (Supabase 화면에만 입력, 이미 저장됨)
  • 구글 클라이언트 보안 비밀번호
  • 카카오 REST API 키 · Client Secret
  • Supabase Database Password · service_role(secret) 키
받은 값으로 Supabase 연결 → 로그인 화면(카카오·구글로 시작) → 여행 데이터 원격 동기화 → 동행자 초대 코드 순으로 구현합니다.
